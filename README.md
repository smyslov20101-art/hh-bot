# hh-bot — AI Job Search Automation

Автоматический поиск AI-вакансий на hh.ru + Telegram-бот для обработки очереди + Google Sheets.

Сделал для себя, чтобы не тратить по 2 часа в день на ручной поиск работы.

## Что умеет

- Ищет вакансии по 5 запросам (`Claude Code`, `AI разработчик`, `Prompt инженер` и др.)
- Жёстко фильтрует: только с зарплатой, только удалёнка/Москва, только AI-стек
- Дедуплицирует через SQLite — одна и та же вакансия не появится дважды
- **Генерирует уникальное письмо под каждую вакансию** — анализирует описание и подбирает нужный акцент
- Отправляет карточки в Telegram-бот с кнопками «Откликнуться» / «Скип»
- Синхронизирует статусы с Google Sheets автоматически

## Архитектура

```
hh.ru (HTML парсинг)
   ↓
daily.py — поиск + фильтр + генерация писем
   ↓
analyzed_vacancies.json — очередь бота
   ↓
@hh_search_bot — карточки с кнопками
   ↓
Google Sheets — трекинг статусов
```

## Почему HTML парсинг, а не API

hh.ru закрыл публичный API для соискателей 15 декабря 2025 года.
Бот парсит HTML напрямую с задержками и retry-логикой чтобы не попасть под блокировку.

## Стек

- **Python 3.12+**
- **aiogram 3** — Telegram Bot
- **httpx** — HTTP клиент с retry
- **BeautifulSoup4** — парсинг HTML
- **SQLite** — дедупликация (через стандартный `sqlite3`)
- **gspread** — Google Sheets API
- **python-dotenv** — конфиг через .env

## Запуск

**1. Установить зависимости:**
```bash
pip install -r requirements.txt
```

**2. Настроить `.env`** (скопировать из `.env.example`):
```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_USER_ID=...
SHEET_ID=...
GOOGLE_CREDS_PATH=./credentials.json
SEARCH_QUERIES=Claude Code,AI разработчик,Prompt инженер,вайб кодер,AI специалист
MIN_SALARY=60000
MAX_VACANCIES=40
```

**3. Google Sheets** — нужен сервисный аккаунт Google Cloud с доступом к таблице.

**4. Ежедневный запуск:**
```bash
python daily.py   # ищет, фильтрует, генерирует письма
```

Потом в Telegram: `/reload` — появятся карточки.

## Генерация писем

Модуль `letter_gen.py` анализирует описание каждой вакансии и подбирает нужный тон:

| Вакансия ищет | Письмо акцентирует |
|---|---|
| Claude Code / вайб-кодинг | «Claude Code — мой основной инструмент ежедневно» |
| Обучение сотрудников | «Умею объяснять технологии простым языком» |
| Автоматизацию | «Строю рабочие инструменты на Python + Claude Code» |
| Google Sheets / интеграции | Подсвечивает hh-bot как проект с Sheets API |

## Фильтр

Автоматически отсекает:
- Без зарплаты
- Не удалёнка и не Москва
- Маркетологов, дизайнеров, продажников
- Не AI-стек (PHP, WordPress, iOS, Android, Go, C++)
- Senior / Lead / Middle+ позиции
- Аналитиков, PM, DevOps

## Файлы

```

├── filters.py        <- строгий фильтр вакансий
├── db.py             <- SQLite дедупликация
├── sheets.py         <- Google Sheets синхронизация
├── tg_queue.py       <- очередь бота
├── tg_presenter.py   <- форматирование карточек
├── requirements.txt

```

## Если hh.ru обрубил соединение

Уменьши `MAX_VACANCIES` в .env до 30, подожди 5-10 минут, запусти снова.
SQLite дедуп помнит что уже видели — потерь не будет.
