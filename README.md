# 🤖 hh-bot — AI Job Search Automation

Бот который сам ищет AI-вакансии на hh.ru, фильтрует мусор и генерирует персонализированные письма под каждую компанию через локальную LLM.

---

## Как это работает

```
daily.py запускается
    ↓
Парсинг hh.ru по 5 поисковым запросам (Claude Code, AI Developer, Prompt Engineer...)
    ↓
Фильтрация: зарплата / формат / стек / дубликаты (SQLite)
    ↓
Генерация письма через Ollama (qwen2.5) — анализ вакансии + персональный хук
    ↓
Telegram-бот показывает карточку вакансии с кнопками
    ↓
Статус (откликнулся / пропустил) → Google Sheets
```

---

## Ключевые технические решения

**Обход VPN-блокировок hh.ru**
hh.ru блокирует запросы через VPN. Решение: отдельный исполняемый файл `python_hh.exe` — копия интерпретатора, которая идёт мимо VPN через Happ split tunneling. Telegram-бот остаётся на VPN и работает стабильно.

**Промпт-инжиниринг против галлюцинаций**
Ollama (qwen2.5) без настройки выдумывает несуществующие проекты в письмах. Решение: системный промпт с запретом галлюцинаций + `temperature: 0.3` + `keep_alive: 15m` для прогрева модели. Письма стали фактически точными.

**Умный лимит отправки**
Счётчик считает отправленные письма, а не попытки. Если компания без email — попытка не тратится, бот берёт следующую.

**Быстрый поиск email**
Раньше: 15 минут на 5 компаний. Сейчас: 7.7 секунды — выходим при первом найденном email.

## Стек

| Компонент | Технология |
|---|---|
| Язык | Python 3.12+ |
| Telegram | aiogram 3 (async) |
| Парсинг | httpx + BeautifulSoup4 |
| LLM | Ollama (qwen2.5) локально |
| База | SQLite (дедупликация) |
| Таблицы | Google Sheets API (gspread) |
